# 💛 Бот знакомств

Телеграм-бот для знакомств, который делает ставку на то, чего обычно не хватает:
понятные правила, живую модерацию и отсутствие платных стен.

```
Без подписок · Без молчаливых банов · Жалобы разбирает человек · Боты не проходят
```

## Чем отличается от большинства ботов

| Как обычно | Как здесь |
|---|---|
| «Кто вас лайкнул» — за подписку | Список входящих лайков открыт всем и всегда |
| Теневой бан без объяснений | Бот прямо пишет: охват снижен, вот причина, вот срок, вот апелляция |
| Жалоба улетает в пустоту | Автор жалобы получает ответ о принятом решении |
| Ботофермы живут месяцами | Верификация селфи, капча, контроль темпа, поиск дублей фото, уровень доверия |
| Лимит лайков ради продажи | Лимит нельзя купить — только заработать, и бот показывает, из чего он сложился |
| Галочка за деньги | Верификация бесплатна, селфи удаляется сразу после проверки |
| «Купи буст, чтобы тебя увидели» | Статистика анкеты с честными советами, что именно улучшить |
| Обмен контактами сразу | Общение внутри бота, номер телефона не раскрывается |

## Возможности

**Для пользователя**

- Анкета за 7 шагов с подсказками, валидацией и предпросмотром
- Лента с лайками, дизлайками и суперлайками; пропущенные анкеты возвращаются через 14 дней
- Входящие лайки бесплатно, суперлайки показываются первыми
- Взаимные симпатии и диалог внутри бота: текст, фото, голосовые, видео, кружки
- Открытый диалог хранится в базе и переживает перезапуск бота
- Автоматическое предупреждение получателю, если в сообщении признаки развода
- Подтверждение анкеты селфи с заданным жестом: галочка ✅, +20 к лимиту лайков
- Выгрузка всех своих данных одним файлом
- Фильтры: пол, возраст, только свой город, только подтверждённые анкеты
- Статистика анкеты за 7 дней с советами, что подкрутить
- Расшифровка своего лимита лайков: за что дали и как увеличить
- Пауза анкеты и полное удаление данных
- Памятка по безопасности: мошенничество, шантаж, первая встреча
- Апелляция на любое ограничение — её читает человек

**Для модератора**

- Очередь жалоб с приоритетами: несовершеннолетние и шантаж идут первыми
- Очередь верификации: селфи и фото анкеты приходят одним альбомом для сравнения
- Стоп-лист фотографий: занесённый снимок больше не загрузить ни с одного аккаунта
- Переписка как доказательство: текст и вложения прямо в панели
- Меры: предупреждение, снижение охвата (3 уровня), блокировка на 1 час / 1 / 7 / 30 дней / навсегда
- Автору жалобы автоматически уходит ответ о решении
- Очередь анкет на проверку, очередь апелляций
- Карточка пользователя: доверие, риск, жалобы, сигналы антифрода, вся активность
- Поиск по ID и @username, журнал всех действий модераторов
- Рассылка с предпросмотром и отчётом о доставке
- Настройки бота (лимиты, пороги модерации, капча) меняются из панели без перезапуска
- Напоминание, если жалоба висит дольше установленного срока

## Установка одной командой

```bash
git clone <репозиторий> && cd Vp && bash install.sh
```

Скрипт всё сделает сам:

1. Найдёт подходящий Python и создаст окружение в `.venv`
2. Установит зависимости
3. Спросит **токен бота** и **ваш Telegram ID** — и проверит токен в Telegram,
   сразу показав, какой бот подключился
4. Сохранит `.env` с правами только для владельца файла
5. Настроит автозапуск: службу systemd, а если systemd нет — собственный сторож
   процесса плюс запуск после перезагрузки через cron
6. Поднимет бота в фоне и убедится, что он действительно работает

```
[3/6] Настройка бота

      Токен бота берётся у @BotFather: /newbot → название → @имя_бота
      Токен бота: 1234567890:AA...
      ✔ токен принят

      Ваш Telegram ID узнаёт @userinfobot — он пришлёт число в ответ на /start
      Ваш Telegram ID: 123456789
      ✔ владелец: 123456789

[4/6] Проверяю токен в Telegram
      ✔ бот найден: @my_dating_bot (Знакомства)
```

Токен берётся у [@BotFather](https://t.me/BotFather), свой Telegram ID — у
[@userinfobot](https://t.me/userinfobot). Повторный запуск `install.sh` безопасен:
он предложит оставить прежние настройки.

Если бот не удержался после старта, установщик не скажет «готово» — он покажет
последние строки лога и подскажет, что проверить.

### Управление

```bash
./manage.sh status     # работает или нет, статистика, последние строки лога
./manage.sh logs       # живой лог (Ctrl+C — выйти)
./manage.sh restart    # перезапуск
./manage.sh stop       # остановить
./manage.sh update     # git pull, зависимости, перезапуск
```

Скрипт сам понимает, как бот установлен, и работает одинаково и со службой
systemd, и со сторожем процесса.

### Как держится режим 24/7

| Ситуация | Что происходит |
|---|---|
| Бот упал с ошибкой | Перезапуск через 5 секунд |
| Сеть пропала надолго | Повтор с растущей паузой до 5 минут, без ограничения числа попыток |
| Неверный токен или `.env` | Перезапуска нет: в логе причина и что исправить, иначе бот бился бы в цикле |
| Сервер перезагрузился | systemd поднимает службу сам; без systemd — задание `@reboot` в cron |
| Лог разросся | Сторож оставляет одну предыдущую копию `bot.log.1`, остальное отбрасывает |

Бот сообщает супервизору код выхода: `0` — штатная остановка, `1` — сбой, который
может пройти сам, `2` — ошибка настройки, которую перезапуск не вылечит.

### Установка вручную

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env               # укажите BOT_TOKEN и OWNER_IDS
.venv/bin/python bot.py
```

### Переменные окружения

| Переменная | Обязательно | Описание |
|---|---|---|
| `BOT_TOKEN` | да | Токен бота |
| `OWNER_IDS` | да | ID владельцев через запятую. Полный доступ, назначают модераторов |
| `MODERATION_CHAT_ID` | нет | Группа для уведомлений модерации. Бот должен быть в ней администратором |
| `SUPPORT_CONTACT` | нет | Контакт поддержки для пользователей |
| `DB_PATH` | нет | Путь к базе, по умолчанию `data/bot.db` |
| `LOG_LEVEL` | нет | `DEBUG`, `INFO`, `WARNING`, `ERROR` |

База данных — SQLite, создаётся сама при первом запуске. Миграции применяются
автоматически по номеру версии схемы, так что обновление бота не требует ручных
действий с базой.

## Как работают ограничения

**Лимит лайков.** Окно скользящее: считаются лайки за последние 24 часа, слоты
освобождаются постепенно. Дизлайки не ограничены. Ответные лайки из раздела
«Мои лайки» лимит не расходуют — отвечать взаимностью должно быть легко, а
разослать так спам невозможно: ответить можно только тем, кто лайкнул первым.

Сам лимит не фиксированный и не продаётся. Он складывается из базы и надбавок за
то, что человек сделал сам, и бот показывает расклад целиком в разделе «Мой лимит
лайков»:

| Слагаемое | Значение |
|---|---|
| База | 30 |
| Заполненная анкета: 2 фото и описание от 30 символов | +10 |
| Подтверждённая анкета (селфи) | +20 |
| Доверие от 70 и аккаунт старше 3 дней | +10 |
| Аккаунт младше суток | −10 |
| Доверие ниже 40 | −10 |

Итог ограничен потолком (по умолчанию 60) — выше не получает никто, это защита от
накруток. Все числа меняются в админ-панели.

**Верификация анкеты.** Бот просит селфи со случайным жестом из списка: показать
два пальца, приложить ладонь к щеке и так далее. Ботоферма такое не выполнит, а
чужая фотография из интернета не подойдёт. Снимок не попадает в анкету, его видит
только модератор, и сразу после решения фото удаляется из базы. Модератор получает
селфи и фотографии анкеты одним альбомом — сравнивать удобно. Подтверждённые
анкеты получают ✅, надбавку к лимиту и небольшой приоритет в ленте; остальные
никуда не пропадают.

**Порядок показа в ленте.** Сначала те, кто уже лайкнул тебя, затем анкеты без
ограничений охвата, затем те, кто заходил недавно. Внутри группы выше поднимаются
анкеты с общими интересами, подтверждённые и совсем новые — чтобы новичок не
утонул в первый же день. Остаток перемешивается случайно, поэтому лента не
выглядит одинаковой.

**Мягкое ограничение охвата** вместо жёсткого теневого бана:

| Уровень | Охват | Что видит пользователь |
|---|---|---|
| 1 — лёгкое | 70% | Сообщение с причиной, сроком и кнопкой апелляции |
| 2 — среднее | 40% | То же |
| 3 — сильное | 15% | То же |

Анкета остаётся в поиске, просто реже попадает в ленту. Люди, которые уже
поставили лайк, видят её как обычно — взаимные симпатии не ломаются.
Ограничение снимается автоматически по таймеру.

**Автоматика не банит.** По жалобам бот может отправить анкету на проверку,
снизить охват или временно скрыть анкету — всё обратимо и с уведомлением.
Блокировку выдаёт только человек.

## Защита от ботоферм

| Сигнал | Реакция |
|---|---|
| Фото занесено модератором в стоп-лист | Такой снимок не принимается ни у кого, запрет снимается одной кнопкой |
| Нет подтверждения селфи | Нет галочки, меньше лимит, не виден в фильтре «только подтверждённые» |
| Селфи не совпадает с анкетой | Анкета скрывается до разбора, сигнал в антифрод |
| Всплеск регистраций за час | Капча для всех новых аккаунтов |
| Нет username и низкое доверие | Капча |
| Слишком ровный и быстрый темп листания | Действие не засчитывается, доверие снижается |
| Лайки почти всем подряд | Честное предупреждение, снижение доверия |
| Одно фото на нескольких аккаунтах | Сигнал модератору, анкета в очередь на проверку |
| Одинаковое описание у разных анкет | То же |
| Реклама, ссылки, номера карт в анкете | Анкета скрывается до проверки модератором |
| Ссылки и просьбы о деньгах в переписке | Предупреждение получателю, сигнал антифрода |

Уровень доверия (0–100) считается из возраста аккаунта, заполненности анкеты,
взаимных симпатий, подтверждённых жалоб и сигналов антифрода. От него зависят
лимиты и строгость проверок.

## Возврат людей без спама

Раз в сутки бот проверяет, у кого накопились непросмотренные лайки, и пишет только
тем, кто не заходил несколько дней. Условия жёсткие: новости должны быть настоящие,
не чаще одного напоминания в неделю, и только если человек не отключил уведомления
о лайках. В самом сообщении сказано, как эти напоминания выключить. Все пороги
настраиваются в админ-панели, механику можно выключить целиком.

## Админ-панель

Откройте `/admin` или кнопку «🛠 Админ-панель» (видна модераторам и владельцам).

Роли: **модератор** разбирает жалобы, апелляции и анкеты; **владелец** дополнительно
назначает модераторов, ведёт рассылку и меняет настройки бота.

Настройки, доступные из панели: лимиты лайков и суперлайков, пороги надбавок,
срок возврата пропущенных анкет, скрытие неактивных, пороги автомодерации,
длительность ограничения охвата, капча, верификация, приоритет новых анкет,
открытие регистрации, срок разбора жалоб, срок хранения переписки.

## Структура проекта

```
install.sh              установка одной командой
manage.sh               start / stop / restart / status / logs / update
scripts/run_forever.sh  сторож процесса для систем без systemd
bot.py                  запуск
app/
  config.py             конфигурация и .env
  constants.py          константы и значения настроек по умолчанию
  texts.py              все тексты бота
  views.py              сборка карточек и сводок
  callbacks.py          данные инлайн-кнопок
  states.py             состояния диалогов
  filters.py            фильтр доступа модератора
  db/                   подключение к SQLite и миграции
  keyboards/            обычные и инлайн-клавиатуры
  middlewares/          антифлуд и загрузка пользователя
  services/             вся логика: лента, лайки, лимиты, жалобы, антифрод,
                        верификация, статистика, диалоги, фоновые задачи
  handlers/             сценарии: регистрация, лента, лайки, симпатии, жалобы, админка
tests/                  проверки логики и сквозные сценарии
```

## Тесты

```bash
ruff check .                # статический анализ
python tests/test_flow.py   # логика и SQL на временной базе
python tests/test_bot.py    # сквозные сценарии через эмулятор Telegram
```

Токен для тестов не нужен: `tests/harness.py` подменяет Bot API и прогоняет
настоящие хендлеры, middleware и состояния. Те же три команды выполняет GitHub
Actions на каждый пуш — файл `.github/workflows/ci.yml`.

## Приватность

Переписка внутри бота хранится ограниченное время (по умолчанию 30 дней) — только
чтобы модератор мог разобрать жалобу по существу. Срок настраивается в панели,
старые сообщения удаляются автоматически. Об этом прямо сказано в правилах,
которые пользователь принимает при регистрации.

Селфи для верификации не показывается в анкете и удаляется из базы сразу после
решения модератора — независимо от того, подтвердили анкету или нет.

Кнопка «📄 Скачать мои данные» в настройках отдаёт файл со всем, что бот хранит о
человеке: анкета, статистика, симпатии, собственные сообщения и история
ограничений. Сообщений собеседников в выгрузке нет — это их данные.

Удаление анкеты стирает анкету, фотографии, лайки, симпатии и переписку.
